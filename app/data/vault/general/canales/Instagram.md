## Integración

- API: **Instagram Messaging API** (vía Graph API de Meta)
- Requiere cuenta de Instagram conectada a una Página de Facebook
- Autenticación: token de acceso de larga duración

## Webhook

```
POST /webhook/instagram
```

## Capacidades

- [ ] Mensajes directos (DM)
- [ ] Respuestas a comentarios
- [ ] Stickers y reacciones

## Notas

- Solo disponible para cuentas de Creador o Empresa
- Los mensajes de voz no están disponibles en la API
